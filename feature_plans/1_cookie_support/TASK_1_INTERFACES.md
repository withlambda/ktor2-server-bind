### Task 1: Define Cookie Interfaces and Data Integration

**Description**: Define marker interfaces for cookies and integrate them into the core `RequestData` and `ResponseData` interfaces in `commonMain`.

**TDD Requirement**:
- **Red Phase**: Write a failing test ensuring that `RequestData` and `ResponseData` currently lack cookie-related properties.
- **Green Phase**: Implement marker interfaces and update the data interfaces.
- **Refactor Phase**: Ensure the new interfaces follow existing library conventions.

**Instructions**:
1.  Create `src/commonMain/kotlin/com/withlambda/ktor2/server/bind/Cookies.kt`:
    - Define `interface Cookies` as a marker interface.
2.  Create `src/commonMain/kotlin/com/withlambda/ktor2/server/bind/request/RequestCookies.kt`:
    - Define `interface RequestCookies : Cookies`.
3.  Create `src/commonMain/kotlin/com/withlambda/ktor2/server/bind/response/ResponseCookies.kt`:
    - Define `interface ResponseCookies : Cookies`.
    - Add `val mapOfCookies: Map<String, Cookie>`.
    - Note: This will be implemented by DTOs where each property corresponds to a cookie to be set, and `mapOfCookies` will collect them (generated by KSP later).
4.  Update `src/commonMain/kotlin/com/withlambda/ktor2/server/bind/request/RequestData.kt`:
    - Add `val cookies: RequestCookies` to `interface RequestData`.
5.  Update `src/commonMain/kotlin/com/withlambda/ktor2/server/bind/response/ResponseDataWithBody.kt`:
    - Add `val responseCookies: ResponseCookies?` to `interface ResponseData`.

**Verification**:
- Successful compilation.
- New properties are visible in `RequestData` and `ResponseData`.
